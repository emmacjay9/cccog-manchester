# Christ's Chosen Church of God International — Manchester Branch

Independent React + Vite website.

## Run locally

1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build for production

npm run build

The production files will be created in `dist/`.

## Deploy cheaply

Recommended options:
- Vercel
- Cloudflare Pages
- Netlify

All can host a small static church website on a free tier, subject to their current terms.
